# 🛠️ Hardware Tools Catalog Web App

เว็บแอปพลิเคชันแคตาล็อกเครื่องมือช่าง (Next.js 16, TypeScript, Tailwind CSS, Supabase, Fuse.js, Lucide Icons, SheetJS) ออกแบบเลย์เอาต์ตามรูปสเก็ตช์ 100% พร้อมระบบค้นหา Fuzzy Search รวดเร็วระดับเสี้ยววินาที ระบบจัดการสต็อกแบบ Real-time เชื่อมต่อแชท LINE OA อัตโนมัติ และระบบหลังบ้าน Admin ครบวงจร

---

## ✨ ฟีเจอร์ที่ได้รับการอัปเกรดล่าสุด (New Updates)

### 1. หน้า Hardware Tools Catalog (ฝั่งลูกค้า)
* 📋 **ปุ่มคลิกคัดลอกรหัสสินค้า (Copy SKU)**: ลูกค้าสามารถคลิกที่ป้ายรหัสสินค้าเพื่อคัดลอกลง Clipboard ได้ทันที พร้อมแอนิเมชันแจ้งเตือน "คัดลอกแล้ว!"
* 🏷️ **แสดงส่วนลดเป็นเปอร์เซ็นต์ (%)**: บอกส่วนลดทั้งจำนวนบาทและเปอร์เซ็นต์อย่างชัดเจน เช่น `ลด ฿360 (-19%)`
* 📦 **แสดงจำนวนคงเหลือในสต็อก**:
  * มีสินค้าพร้อมส่ง (คงเหลือ x ชิ้น)
  * เตือนเมื่อใกล้หมด เช่น `เหลือเพียง 3 ชิ้น`
  * สินค้าหมดชั่วคราว
* 📑 **ระบบ Pagination (แบ่งหน้า)**: มีปุ่มเปลี่ยนหน้า เลือกรวมแสดงผล 6, 12, 24 หรือทั้งหมดต่อหน้า
* 🔀 **ระบบ Sorting (การจัดเรียง)**:
  * สินค้ามาใหม่ล่าสุด
  * ยี่ห้อ (A-Z / Z-A)
  * ชนิดเครื่องมือ / หมวดหมู่ (ก-ฮ)
  * รหัสสินค้า SKU
  * ราคา (ต่ำสุด-สูงสุด / สูงสุด-ต่ำสุด)
  * ส่วนลดบาท และ ส่วนลด % สูงสุด
  * สต็อกคงเหลือ (มากสุด / น้อยสุด)

### 2. หน้า Admin Catalog Management (ระบบจัดการหลังบ้าน)
* 🔢 **จัดการจำนวนคงเหลือในสต็อก**: แสดงจำนวนคงเหลือในตาราง พร้อมปุ่ม +/- ปรับจำนวนได้ทันที และสวิตช์ Toggle สถานะ
* 🏷️ **แสดงส่วนลดครบทั้ง ฿ และ %**: แสดงยอดส่วนลดคู่กับเปอร์เซ็นต์ในตาราง
* 🔀 **ปุ่ม Sort หัวตารางแบบ Interactive**: คลิกที่หัวคอลัมน์ใดก็ได้ (SKU, ชื่อ, ยี่ห้อ, หมวดหมู่, ราคา, ส่วนลด, สต็อก) เพื่อจัดเรียงจากน้อยไปมาก/มากไปน้อย
* 📑 **Pagination ในตารางแอดมิน**: เลือกรอบการแสดงผล 10, 25, 50 หรือทั้งหมดต่อหน้า

### 3. & 4. หน้าเพิ่มและแก้ไขข้อมูลสินค้า (Add / Edit Modals)
* 🔍 **Dropdown ยี่ห้อและหมวดหมู่แบบค้นหาได้ (Searchable Combobox)**:
  * สามารถพิมพ์ค้นหาในช่อง Dropdown ได้ทันที
  * หากพิมพ์ยี่ห้อ/หมวดหมู่ใหม่ที่ยังไม่มี สามารถคลิก `+ เพิ่มใหม่` ได้จากใน Dropdown ทันที
* 🔢 **ช่องกรอกจำนวนคงเหลือในสต็อก**: ปรับสต็อกเริ่มต้นและซิงค์กับสถานะพร้อมส่งอัตโนมัติ
* 💸 **สลับการกรอกส่วนลดได้ทั้ง ฿ และ %**: มีปุ่มสลับว่าจะกรอกเป็นบาทหรือเปอร์เซ็นต์ ระบบจะคำนวณราคาหลังลดและอีกค่าหนึ่งให้แบบเรียลไทม์

### 5. พื้นที่จัดการยี่ห้อและหมวดหมู่ (Brand & Category Management)
* 🏷️ **ปุ่ม "จัดการยี่ห้อ & หมวดหมู่" ที่แถบเครื่องมือแอดมิน**:
  * ดูรายการยี่ห้อและหมวดหมู่ทั้งหมด พร้อมจำนวนสินค้าที่กำลังใช้งาน
  * เพิ่มยี่ห้อใหม่ / เพิ่มหมวดหมู่ใหม่
  * ลบยี่ห้อ / ลบหมวดหมู่ (มีระบบแจ้งเตือนหากมีสินค้าใช้งานอยู่)
  * เชื่อมต่ออัตโนมัติกับตัวเลือกใน Dropdown, ชิปตัวกรอง และ Sorting ทันที

## 🖼️ การจัดการรูปภาพสินค้า (Image Management)

### วิธีที่ 1: ใส่ Image URL ในไฟล์ CSV / Excel แล้วกด Import
1. ใส่คอลัมน์ชื่อ `image_url` (หรือ `รูปภาพ`, `รูป`, `image`) ในไฟล์ CSV/Excel
2. ใส่ลิงก์รูปภาพ เช่น `https://images.unsplash.com/...` หรือลิงก์จาก Supabase Storage / Google Drive
3. กดปุ่ม **"Import Excel / CSV"** ในหน้า Admin ระบบจะดึงรูปภาพมาแสดงให้อัตโนมัติทันที
*(ระบบมีตัวแปลงลิงก์ Google Drive ให้แสดงผลเป็นภาพแท้โดยอัตโนมัติ)*

### วิธีที่ 2: ระบบ Batch Upload รูปภาพตาม SKU (มีไฟล์รูปอยู่ในคอมฯ)
1. ตั้งชื่อไฟล์รูปภาพให้ตรงกับรหัสสินค้า เช่น `SATA-09014.jpg`, `ASAHI-CLS100.png`
2. ในหน้า Admin คลิกปุ่ม **"อัปโหลดรูปชุด (ตาม SKU)"** แล้วเลือกไฟล์รูปภาพทั้งหมดพร้อมกัน (กี่สิบรูปก็ได้)
3. ระบบจะอัปโหลดรูปทั้งหมดเข้า Supabase Storage และจับคู่ SKU ผูกรูปภาพเข้ากับสินค้าในฐานข้อมูลให้อัตโนมัติทันที!
